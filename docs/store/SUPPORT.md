## Frequently asked questions

**Does StoreFlow need internet?**
No. It works fully offline. All data stays on your computer.

**Is there a monthly fee?**
[Describe your pricing.]

**Can I use it on more than one computer?**
Each computer has its own database. Use one main computer for the shop. To
move to a new computer, create a backup and restore it on the new one.

**Which printers work?**
Any printer installed in Windows, including 58 mm and 80 mm thermal receipt
printers. Choose the paper size in Settings → Receipt designer.

**Which barcode scanners work?**
Any USB scanner that works as a keyboard (most scanners). The webcam can also
scan EAN, UPC, Code 128 and QR codes.

**I forgot the owner password.**
Use *Forgot password* on the sign-in screen with the recovery key shown at
setup. Without the key the password cannot be recovered, so keep it safe.

**How do I keep my data safe?**
Settings → Data & backup → turn on automatic backups to an external drive or
a cloud-synced folder, and create a backup before big changes.

**How do I delete all my data?**
Uninstall the app. The Microsoft Store version removes its data folder;
keep a backup first if you may need the data later.
